# Overview

The Weather Application provides users with real-time weather updates for any location. It utilizes the OpenWeather API to fetch weather data, including current temperature, humidity, weather conditions, and more. The app also offers location-based weather predictions using GPS services.

Features

Real-time Weather Updates:
Get the current temperature, humidity, and weather conditions. <br>
View weather forecasts for the next few days.<br>
Location Services:<br>
Automatically fetch weather based on the device's location.<br>
Search for weather in any city around the world.<br>

User-friendly Interface:

Clean and modern UI built using Jetpack Compose.<br>
Supports dark mode.<br>

Technologies Used<br>
Frontend:

Android Studio (Java/Kotlin)<br>
Jetpack Compose for UI<br>
Retrofit for API calls to the OpenWeather API<br>
Fused Location Provider API for GPS<br>

Backend API:

OpenWeather API for fetching weather data<br>
